# Kalp Hastalığı Tahmini (Sınıflandırma Projesi)

Bu proje, hastaların klinik verilerini kullanarak kalp hastalığı riski taşıyıp taşımadığını tahmin eden makine öğrenmesi modellerini içerir.

## 📊 Veri Seti
Projede Kaggle üzerinden alınan **Heart Disease UCI** veri seti kullanılmıştır.
* **Veri Seti Linki:** [Kaggle - Heart Disease Data](https://www.kaggle.com/code/zeeshanyounas001/heart-disease-uci/input)
* **Veri Özeti:** Toplam 920 kayıt bulunmaktadır (509 hasta, 411 sağlıklı). Sınıflar dengelidir.
